# Experiments

Released implementations are grouped by the corresponding manuscript study. Every public driver receives run parameters through its command-line interface.

- `manufactured_solutions/`: five Figure 3 benchmarks.
- `allen_cahn/`: volume-constrained Allen--Cahn on a disk.
- `burgers/`: nonlinear vector Burgers on an embedded square.
- `inverse_discovery/`: sparse law identification on peanut and channel domains.
- `cylinder_wake/`: cylinder-wake study.
- `swift_hohenberg/`: clamped Swift--Hohenberg study.
